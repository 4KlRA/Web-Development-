# Landing Page

A single-page website built as a The Odin Project Foundations project. The exercise brings together HTML structure and CSS styling, with Flexbox used to arrange the major sections and their contents.

## Page sections

- **Header:** brand/logo text and a group of navigation links.
- **Hero:** primary headline, supporting copy, call-to-action button, and image placeholder.
- **Information section:** a heading followed by a row or group of informational items.
- **Quote/testimonial:** a longer quotation with attribution.
- **Call to action:** a final prompt and sign-up action.
- **Footer:** closing page information.

## Implementation

- `index.html` contains the page content and section structure.
- `style.css` contains the presentation rules and is linked externally.
- Flexbox is used for header alignment, hero content, navigation, and grouped information/layout elements.
- A shared maximum-width content container keeps major sections aligned.
- CSS customisation includes typography, color, spacing, backgrounds, and button styling.

## Run locally

Open `index.html` in a modern web browser. The project is static HTML and CSS and does not require a development server or package installation.

## Skills practised

- Translating a visual reference into a sequence of page sections.
- Structuring a landing page with HTML.
- Using an external stylesheet and reusable CSS classes.
- Applying Flexbox to align and distribute page content.
- Controlling content width, spacing, typography, and visual hierarchy.
