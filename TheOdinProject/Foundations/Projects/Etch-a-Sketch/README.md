# Etch-a-Sketch 🎨

A simple browser-based Etch-a-Sketch application built using **HTML, CSS, and JavaScript**. Create a sketch by hovering over a grid of squares and watch the drawing area come to life!

## ✨ Features

- **Interactive Grid:** Hover over individual squares to color them.
- **Custom Grid Size:** Click the Reset button to choose the number of rows and columns.
- **Dynamic Grid Generation:** The grid is generated dynamically using JavaScript.
- **Grid Size Validation:** Prevents users from creating grids larger than 100 × 100.
- **Responsive Drawing Logic:** Each square is sized automatically based on the selected grid dimensions.

## 🛠️ Technologies Used

- HTML5 – Application structure.
- CSS3 – Styling and hover effects.
- JavaScript – DOM manipulation, event handling, and dynamic grid creation.

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd etch-a-sketch
   ```

3. Open `index.html` in your browser.

## 🎮 How to Use

1. Open the application in your browser.
2. Click the **Reset** button.
3. Enter the desired number of rows and columns (up to 100).
4. Hover over the grid squares to draw.
5. Click **Reset** again to create a new grid with a different size.
