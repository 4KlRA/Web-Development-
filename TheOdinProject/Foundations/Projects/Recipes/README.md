# 🍽️ Recipes Website

Welcome to my first web development project!

This is a simple **Recipes Website** built using HTML and is now also being used to practise writing Css with an external stylesheet. 

## 📖 About the Project

The website provides a homepage from which users can open three individual recipe pages. Each recipe page contains a description, an ingredient list, and step-by-step preparation instructions.

## ✨ Features

- Homepage with links to all three recipes.
- Individual pages for each recipe.
- Recipe descriptions and ingredient lists.
- Nested lists for ingredient groups and preparation steps.
- Recipe images with alternative text.
- Navigation back to the homepage.
- One shared external stylesheet connected to all four HTML pages.

## 🍕 Available Recipes

1. **Lasagna** – Indian-style vegetable and paneer lasagna.
2. **Pasta** – Creamy Makhani Sauce Pasta.
3. **Pizza** – Paneer Butter Masala Pizza.

## 🛠️ Technologies Used

- HTML5 document structure.
- Headings, paragraphs, and strong text.
- Ordered, unordered, and nested lists.
- Links and images.
- Relative paths for page navigation and stylesheet references.
- External CSS using a shared `style.css` file.
- CSS element and grouped selectors.
- CSS image sizing with `width`, `height`, and `auto`.
- CSS list line-height and link color/text-decoration declarations.
- Further practice with text/background colors and typography is part of this exercise; those declarations can be added as they are explored.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the `Recipes` project folder.
3. Locate and open `index.html` in your web browser.
4. Browse the recipes by clicking on their links.

- Structuring content with headings, paragraphs, and lists.

- Adding images and descriptive alternative text.
