# 🍽️ Recipes Website

Welcome to my first web development project!

This is a simple **Recipes Website** built using HTML. It features three delicious recipes with their descriptions, ingredients, and step-by-step cooking instructions.

## 📖 About the Project

The Recipes Website is designed to provide users with easy access to different recipes through a simple homepage.

Users can browse the available recipes and click on any recipe to view its ingredients and preparation steps.

## ✨ Features

- Simple and clean homepage.
- Three different recipes.
- Individual pages for each recipe.
- Recipe descriptions and ingredient lists.
- Step-by-step cooking instructions.
- Navigation back to the homepage.

## 🍕 Available Recipes

1. **Lasagna** – Indian-style vegetable and paneer lasagna.
2. **Pasta** – Creamy Makhani Sauce Pasta.
3. **Pizza** – Paneer Butter Masala Pizza.

## 🛠️ Technologies Used

- HTML5
- Basic HTML elements and tags.
- Hyperlinks for page navigation.
- Images to display the recipes.

## 📁 Project Structure

```text
Recipes/
│
├── index.html
│
└── recipes/
    ├── lasagna.html
    ├── pasta.html
    └── pizza.html
```

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Locate `index.html`.
4. Open `index.html` in your web browser.
5. Browse the recipes by clicking on their links.
