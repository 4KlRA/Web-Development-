# 🌱 The Odin Project – Foundations

This folder contains my exercises, and projects from **The Odin Project Foundations** curriculum.

The purpose of this section is to develop a strong understanding of the fundamentals of web development through hands-on practice.

## 📚 Topics Covered

### 1. Working with Text

Folder: `Working with Text/`

Practised:

- Using headings and paragraphs.
- Making text bold using `<strong>`.
- Emphasizing text using `<em>`.
- Understanding basic HTML text formatting.

### 2. Lists

Folder: `Lists/`

Practised:

- Creating unordered lists using `<ul>`.
- Creating ordered lists using `<ol>`.
- Adding list items using `<li>`.
- Organizing information into structured lists.

### 3. Links and Images

Folder: `links-and-images/`

Practised:

- Creating links using the HTML anchor element.
- Linking between local webpages.
- Linking to external websites.
- Adding images using the HTML image element.
- Using relative file paths.
- Understanding image attributes such as `src`, `alt`, `width`, and `height`.

### 4. Projects

Folder: `Projects/`

#### Recipes Website

My first HTML project!

A simple multi-page recipe website featuring:

- Indian-style vegetable and paneer lasagna.
- Creamy Makhani Sauce Pasta.
- Paneer Butter Masala Pizza.

The project practises HTML document structure, links, images, lists, and navigation between webpages.
